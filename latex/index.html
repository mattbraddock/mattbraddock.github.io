LaTeX Recipes

Packages

Defaults: 
\usepackage[T1]{fontenc}
\usepackage{amsmath,mathtools}
\usepackage{graphicx}
\usepackage{tabularx}
\usepackage{tikz}
Page margins: 
\usepackage[top=22mm,bottom=22mm,left=17mm,right=17mm]{geometry}
Paragraph spacing: 
\usepackage{parskip}

Formatting

Move title vertically: 
\usepackage{titling}
\setlength{\droptitle}{-5em}
Remove paragraph indenting: 
\setlength{\parindent}{0pt}
Remove page numbers: 
\pagenumbering{gobble}
Temporary indentation: 
\usepackage{changepage}
\begin{adjustwidth}{10mm}{}
...
\end{adjustwidth}
Headers and footers: 
\usepackage{fancyhdr}
\pagestyle{fancy}
\setlength{\headheight}{14pt}
\fancyhead[L]{}
\fancyhead[C]{}
\fancyhead[R]{}
\fancyfoot[L]{}
\fancyfoot[C]{}
\fancyfoot[R]{}
% change rule width as needed
\renewcommand{\headrulewidth}{0pt}
\renewcommand{\footrulewidth}{0pt}
Different headers and footers on first page: 
\fancypagestyle{firstpage}{
    \fancyhead[L]{}
    \fancyhead[C]{}
    \fancyhead[R]{}
    \fancyfoot[L]{}
    \fancyfoot[C]{}
    \fancyfoot[R]{}
}
% add the following just after \begin{document}
\thispagestyle{firstpage}
Two columns: 
\begin{minipage}[t]{0.48\textwidth}
...
\end{minipage}\hspace{0.03\textwidth}
\begin{minipage}[t]{0.48\textwidth}
...
\end{minipage}

Commands

Usage: $\arc{AB}$ Arc notation in math mode: 
\newcommand{\arc}[1]{
	{\setbox9=\hbox{#1}\ooalign{
		\resizebox{\wd9}{\height}{\texttoptiebar{\phantom{A}}}\cr#1
	}}
}
Usage: \blankline{15mm} will produce a bottom-aligned line that is 15mm long Blank write-in line: 
\newcommand{\blankline}[1]{
	\parbox{#1}{\vtop{\vskip1em \hrulefill}}
}
Usage: \insertimage{0.5}{image.png} will add image.png with width equal to 50% the text width Insert image: 
\newcommand{\insertimage}[2]{
	\includegraphics[width=#1\textwidth,keepaspectratio=true]{#2}
}
